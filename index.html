WEB APPLICATION • SIMULATION & VISUALIZATION

VENJIX — A MULTIVERSE DEEPDIVE

An original, interactive multiverse simulation web application designed to model, compute, and visualize counterfactual human decision pathways. Venjix allows users to explore alternate personal timelines, observe compounding divergences over 1, 5, and 10-year horizons, and interact with parallel manifestations of their identity through specialized cosmic interfaces.

01 // PROBLEM STATEMENT & CONCEPT

Human lives are defined by pivotal fork-in-the-road decisions—such as pursuing an engineering degree versus competitive cricket, or relocating across continents. Standard retrospectives lack visual and computational models to explore how counterfactual trajectories compound over time. Venjix addresses this by modeling alternative causal branches, simulating how a single divergent decision fundamentally alters life trajectory, career, philosophy, and personal identity across structured temporal horizons.

02 // INDIVIDUAL CONTRIBUTION

Sole Creator & Lead Engineer: Conceived, architected, and built Venjix entirely from scratch as an original concept. Authored the system architecture, component layouts, visual pipelines, and interactive flows. Leveraged Antigravity as an advanced AI-assisted development tool for rapid iterative prototyping, algorithmic reasoning, and code acceleration while maintaining full ownership of technical decisions and architectural direction.

03 // CURRENT STATUS & IMPLEMENTATION SCOPE

Transparent Assessment Disclosure: The application interface, interactive reality navigation, timeline comparison flows, and audio synthesizer are fully deployed and interactive on Vercel. However, alternate timeline narrative generation currently returns structured predefined simulation templates rather than dynamically personalized text. The Parallel Self and Enigma Oracle modules operate in a SIMULATION FALLBACK mode with canned conversational responses; live streaming AI integration via external LLM APIs remains an active area of ongoing backend development.

04 // SOLUTION & VERIFIED FUNCTIONALITY
  • Cosmic Observatory: An interactive node-based visual explorer allowing navigation through divergent reality clusters and dimensional coordinates.
  • Reality Forge: Multi-step input pipeline capturing user baseline reality parameters and injecting pivotal counterfactual decision nodes.
  • Alternate Timeline Creation: Choreographed temporal engine synthesizing divergent career, lifestyle, and mindset outcomes over 1, 5, and 10-year milestones.
  • Timeline Comparison: Comparative analytical interface evaluating divergent realities against baseline life metrics.
  • Parallel Self: Conversational terminal interface designed for dialogue with a counterfactual version of oneself (operating in simulation fallback).
  • Enigma Oracle: Dedicated inquiry engine designed for querying multiversal principles, temporal mechanics, and philosophical dilemmas.

PROJECT // 02 STATUS // IN DEVELOPMENT
WEB APPLICATION • E-COMMERCE PLATFORM

RAGADHNI — INDIAN WOMEN'S FASHION

A modern, high-performance digital fashion storefront engineered exclusively for an independent Indian women's apparel brand. Ragadhni delivers a curated shopping experience bridging authentic ethnic heritage (sarees, kurtas, and salwar sets) with contemporary Western fusion, everyday casual wear, and tailored dresses & leggings.

01 // PROBLEM STATEMENT & BRAND CONCEPT

Online shopping for Indian women's clothing is frequently burdened by cluttered legacy marketplace UIs, sluggish category filtering, and disjointed transitions between traditional ethnic collections and modern casual styles. Ragadhni was conceived as a bespoke, brand-first fashion platform focused strictly on women's apparel. The goal is to provide seamless visual discovery, rapid client-side filtering, and an accessible, editorial shopping experience that respects the cultural craft of Indian garments while offering competitive pricing.

02 // INDIVIDUAL CONTRIBUTION

Sole Creator & Developer: Originated the brand concept, women's apparel product taxonomy, and storefront design. Built the complete Next.js frontend architecture from the ground up, implementing the modular React component library, responsive navigation mega menus, interactive product grid, and client-side cart/wishlist management system utilizing AI-assisted development tools to accelerate implementation.

03 // CURRENT STATUS & IMPLEMENTATION SCOPE

Transparent Assessment Disclosure: The client-side storefront architecture, responsive layouts, apparel taxonomy, dynamic product browsing, and cart/wishlist React Context state flows are fully developed and testable in local development. Production backend operations—including live payment gateway checkout (e.g., Razorpay/Stripe), user auth sessions, transactional order webhooks, and production PostgreSQL database sync via Prisma—are actively in development and pending deployment.

04 // SOLUTION & VERIFIED FUNCTIONALITY
  • Apparel-First Taxonomy: Specialized catalog structure strictly curated for women's wear across Ethnic & Traditional, Contemporary Fashion, Casual Daily Wear, and Dresses & Leggings.
  • Responsive Mega Menus: Multi-tiered header navigation providing instant category jumps and collection discovery across mobile drawers and desktop viewports.
  • Interactive Product Displays: Dynamic garment cards featuring image hover previews, size variant selectors, price discount indicators, and stock badges.
  • Reactive Cart Management: Centralized client-side shopping bag powered by React Context, supporting real-time item additions, quantity modifications, subtotal calculation, and instant drawer previews.
  • Wishlist System: Persistent wishlist toggling allowing shoppers to save garments across browsing sessions.
  • Session Synchronization: Hydration-safe LocalStorage integration ensuring active cart contents and saved wishlist garments survive browser refreshes.
